# Code of Conduct

Be kind, be respectful, stay on topic. This project deals with intimate
devices — keep discussions technical, consent-focused and free of harassment,
discrimination or explicit content.

Maintainers may remove comments, issues or contributions that don't follow
these rules, and block repeat offenders. Report problems through a private
GitHub security advisory or by contacting the maintainer via their GitHub
profile.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
